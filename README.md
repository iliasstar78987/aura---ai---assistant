# Aura AI — Unlimited OpenRouter AI Super Assistant (অরা এআই)

একটি আধুনিক, সুরক্ষিত ও কন্ডিশনহীন পার্সোনাল এআই সুপার অ্যাসিস্ট্যান্ট ওয়েব অ্যাপ্লিকেশন। ওপেন রাউটার এপিআই (OpenRouter API) ইন্টিগ্রেশন, আনলিমিটেড চ্যাট, ফ্রি হাই-রেজোলিউশন ইমেজ জেনারেশন, দীর্ঘমেয়াদী মেমোরি ভল্ট এবং মিলিটারি গ্রেড AES-256 GCM এনক্রিপশনের সুবিধা রয়েছে।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

- ⚡ **OpenRouter API Integration**: সরাসরি ওপেন রাউটার কী যুক্ত করে Llama 3.3 70B (Free), DeepSeek R1 (Free), Gemini 2.0 Flash (Free), Claude 3.5 Sonnet, GPT-4o এবং যেকোনো কাস্টম মডেল ব্যবহারের সুবিধা।
- 🎨 **Unlimited Image Generation**: চ্যাটে `/image <প্রম্পট>` লিখে অথবা ডেডিকেটেড ইমেজ স্টুডিও থেকে ইচ্ছামতো রেশিও (1:1, 16:9, 4:3, 9:16) ও স্টাইলে (Realistic, Cinematic, Anime, Cyberpunk, 3D) সীমাহীন ছবি তৈরি করুন।
- 🔐 **Military-grade AES-256 GCM Encryption**: ব্যবহারকারীর সকল চ্যাট হিস্ট্রি, এপিআই কী এবং ব্যক্তিগত মেমোরি ব্রাউজারে সুরক্ষিত রাখতে ক্লায়েন্ট-সাইড এনক্রিপশন ও পাসফ্রেজ সুরক্ষা।
- 🧠 **Smart Memory Vault**: ব্যবহারকারীর নাম, পছন্দ, পেশা এবং নির্দেশনা দীর্ঘমেয়াদে মনে রেখে প্রতিটি কথোপকথনে ব্যক্তিগত অভিজ্ঞতা প্রদান করে।
- 🎭 **Adaptive Moods & Personas**: ৫টি বিশেষ মেজাজ — বন্ধুত্বপূর্ণ (Friendly), বিশ্লেষক (Analytical), রসিক (Humorous), সহানুভূতিশীল (Empathetic), এবং সৃজনশীল (Creative)।
- 🎙️ **Voice Command & Audio Readout**: বাংলা (`bn-BD`) ও ইংরেজি (`en-US`) ভাষায় স্পিচ-টু-টেক্সট ভয়েস কমান্ড এবং টেক্সট-টু-স্পিচ (TTS)।
- 🌐 **Web Link Inspector**: যেকোনো ওয়েবসাইট লিংক পেস্ট করলে মেটাডাটা ও প্রাসঙ্গিক ছবি চ্যাটে বিশ্লেষণ করে উপস্থাপন করে।
- 🌓 **Themes & Bilingual**: এক ক্লিকে বাংলা/ইংরেজি ভাষা পরিবর্তন, ডার্ক মোড, ওলেড পিওর ব্ল্যাক এবং লাইট মোড।

## 🚀 লোকাল সেটআপ ও রান করার নিয়মাবলী

### প্রয়োজনীয়তা:
- Node.js (v18 বা পরবর্তী সংস্করণ)
- npm বা bun

### ইনস্টলেশন ও রান:

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন (Port 3000)
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```
